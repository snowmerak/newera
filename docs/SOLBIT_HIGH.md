# 솔빛고, 가을제까지 열흘

25명 모두에게 플레이어가 아는 초기 관계, 기본 외모, 옷·음식 취향과 옷차림 후보 3개씩을 설정했다. 공개 초기 관계는 최초 등장에만, 인상착의는 최초 등장과 차림이 바뀐 뒤의 첫 등장에만 레이블 없는 문단으로 표시한다. 옷은 첫 등장·날짜 변경 또는 마지막 선택 이후 180분 이상 지나 다른 씬에 등장할 때 판단 모델이 다시 선택할 수 있다. 간격은 세계관 편집에서 수정한다. [상세 계약](CHARACTER_PRESENTATION.md)을 참고한다.

현대 한국의 가상 소도시 해온시에 있는 남녀공학 고등학교. 교문에서 시작해 수업을 마친 학생들의 일상, 동아리와 축제 준비, 귀가 약속을 오가며 가벼운 미스터리를 선택적으로 따라가는 SFW 세계관이다. 초능력이나 확정된 범죄는 없다.

## 사용

- 작성 원본: [solbit-high.json](../lore-sources/solbit-high.json)
- 가져오기 파일: [solbit-high.json](../static/lore-presets/solbit-high.json)
- 작업실의 **저장한 세계관 가져오기**에서 가져오기 파일을 선택한다. 새 세계관이 생기며 이전 세계관과 세이브는 유지된다.
- 솔빛고를 새 버전으로 바꾸려면 기존 항목을 연 뒤 **가져오기 방식 → 현재 세계관 교체**를 선택한다. 기존 진행과 슬롯은 버리고 파일의 시작 상태로 교체한다. 이미 중복으로 가져온 항목은 해당 항목을 선택하고 **현재 세계관 삭제**에서 지울 수 있다.
- 플레이어는 2학년 3반 전학생. 이름·성별·취향은 플레이 중 정한다. 시작 시각은 엔진의 기본값인 1일차 18:00으로, 설정의 수요일 방과후와 일치한다. 이서우는 원래 이 학교에 다니던 같은 반 재학생이며 첫 안내 동행이다. 오늘 전학 온 사람은 플레이어다.
- 실제 생성·판단 모델은 가져온 세션의 모델 설정에서 고른다. 파일에 특정 모델이나 토큰 설정을 고정하지 않는다.

다음 명령으로 원본을 다시 빌드하고 검증한다.

```powershell
npm run lore:build -- lore-sources/solbit-high.json static/lore-presets/solbit-high.json
npm run lore:validate -- lore-sources/solbit-high.json
npm run lore:validate -- static/lore-presets/solbit-high.json
```

씬 **44개**, 직접 연결 **50쌍**(모두 양방향), 학생 **20명**, 교직원 **4명**, 학교 앞 문방구 주인 **1명**, 오브젝트 **49개**. 총 인스턴스는 **74개**다. 교내 인구 540명은 배경 설명이며 명시한 인물 외의 대사나 행동을 실행기가 자동 생성하지 않는다.

## 처음 해볼 만한 선택

1. 서우에게 학교 안내를 부탁하되 어디부터 갈지 직접 고른다. 문방구 배달 문제는 도와주거나 거절할 수 있다.
2. 새 반에서 다은의 역할 표와 세진의 대본을 보고, 축제 참가 여부와 맡고 싶은 일을 정한다.
3. 합주와 귀가 시간이 겹친 하린·민재의 대화, 체육관과 행사 동선이 겹친 보라·채원의 조정을 지켜본다.
4. 도서관에서 해솔에게 책을 추천받거나 온실에서 나리와 이름표 문구를 고친다. 미스터리에 참여하지 않아도 할 일이 있다.
5. 빈 손종 받침대가 궁금하면 준비실·방송실·기록 자료를 비교하고, 누가 무엇을 직접 아는지 물어본다.

거절해도 반 소속이나 사람으로서의 가치를 잃는 설정이 아니다. 모든 NPC가 플레이어를 좋아하거나 따라다니지 않으며, 또래의 호감은 대화와 관찰에 따라 달라질 수 있다.

## 인물 설정과 관계

성격은 대사 말투뿐 아니라 스트레스 때 고르는 방법, 능력의 한계, 거절하거나 수정하는 조건을 포함한다. 초기 관계에는 신뢰·호감·친밀·존중·경계와 서로 다른 인식이 들어 있다. 예를 들어 지수는 예린의 취재 능력을 인정하면서 사진의 오용을 경계하고, 하린은 민재의 연주를 믿으면서 지각에 서운함도 느낀다. 플레이어는 처음 만난 사람으로 평가를 시작한다. 관계 수치는 초기값이며 이후 목격 사건으로 갱신된다.

초기 개인 지식은 캐릭터 자신의 `state.knownFacts`, 첫 의도는 `state.initialIntention`에 넣었다. 다른 인물이 보는 공개 소개에는 해답을 쓰지 않았다. 동적 개인 메모는 엔진의 `memo`로 시작 후 갱신되며 초기에는 null이다. 실제로 발생하지 않은 초기 사건·대사·목격 기억은 만들지 않았다.

### 이서우

솔빛고에 이미 재학 중인 2학년 3반 학생. 오늘 전학 온 플레이어의 학교 안내 담당. 길과 사람의 사소한 취향을 잘 기억한다. 누구와도 가볍게 말을 트지만 부탁을 거절하는 속도는 느리다. 접었다 편 작은 안내 지도를 들고 있다.

- 말투와 선택 성향: 친근한 반말을 쓰되 처음에는 반말해도 되는지 묻는다. 설명할 때 갈림길 두 개를 먼저 짚고 상대의 선택을 기다린다. 안내를 잘하는 자신을 좋아하지만 남의 일정까지 떠맡으면 지친다. 아는 길과 모르는 사정은 구분한다. 상대를 재촉하거나 모든 장소를 억지로 순회시키지 않는다. 무안할 때 웃음으로 넘기다가도 자기 약속 시간은 분명히 말하려 한다.
- 현재 목표: 전학생이 원하는 첫 장소까지 길을 안내한다 / 18시 30분 전에 다은에게 인쇄한 준비표를 건네고 자기 시간을 확보한다
- 첫 의도: 어디부터 가고 싶은지 묻고 선택한 한 장소를 안내하려 한다. 현재 동행으로 배치되어 있지만 상대의 동의와 자기 일정이 중요하다.
- 상대별 인식:
  - 강다은: 내 친절을 알아주는 반장이지만 부탁을 거절하기 어렵다.
  - 노유준: 풀이를 잘 설명하던 친구. 미룬 약속을 먼저 꺼내기 민망하다.
  - 오지수: 내 말보다 실제 표정을 잘 봐주는 친구.
  - 플레이어: 오늘 처음 안내를 맡은 전학생. 원하는 장소와 말투부터 물어보고 싶다.

### 강다은

솔빛고 2학년 학생. 2학년 3반 반장. 준비표의 빈칸부터 눈에 들어오는 꼼꼼한 반장. 작은 수첩에 맡은 사람보다 아직 맡지 않은 일을 먼저 적는다. 남에게 떠넘기는 것을 싫어해 결국 자기 할 일을 늘린다.

- 말투와 선택 성향: 동급생에게 짧고 명료한 반말, 교사에게 정확한 존댓말을 쓴다. 지시보다 누가 언제까지 가능한지 먼저 묻는다. 안심시키려고 근거 없이 다 됐다고 말하지 않는다. 일정이 틀어지면 말수가 줄고 항목을 잘게 쪼갠다. 계획을 무시당하는 데 민감하지만 좋은 대안을 들으면 자기 표도 고친다.
- 현재 목표: 오늘 안에 반 부스의 역할 두 자리를 자발적인 지원으로 채운다 / 서우의 친절을 당연하게 쓰지 않고 자기 부담도 나눈다
- 첫 의도: 빈 역할을 대신 떠맡기 전에 원하는 일을 물어볼 생각이다.
- 상대별 인식:
  - 이서우: 믿고 맡길 수 있는 친구. 그래서 너무 자주 맡기는 건 아닌지 신경 쓰인다.
  - 한도현: 조정 능력은 좋지만 부드러운 말 때문에 확인이 늦어질 때가 있다.
  - 차은경: 내가 혼자 하는 일을 알아차리는 담임. 도움을 청하는 일은 아직 서툴다.

## 현재 실행기의 한계

전체 학교의 수업·동선·종을 시간표대로 자동 시뮬레이션하지 않는다. 현재 씬의 인물만 판단하며 다른 씬으로 떠난 인물은 플레이어가 그 씬에 도착하기 전까지 계속 행동하지 않는다. 첫 안내 동행은 이서우 한 명으로 배치하며, 현재 엔진에서 동행을 바꾸려면 작업실의 배치·관계 편집을 사용한다. 대사만으로 companion 필드가 자동 변경되지는 않는다. 권한이 필요한 공간의 예절은 서사 규칙이며 물리적 잠금 검사는 없다. 개인정보나 위험한 비개방 구역을 놀이 대상 씬으로 만들지 않았다.

이 세계관은 새 기능을 구현한 것이 아니라 현재 실행기에 맞춘 콘텐츠다. 가을제 D-10 같은 배경 표기는 자동으로 감소하는 퀘스트 카운터가 아니며 실제 시계·사건·개인 메모를 우선한다. 저장·초기화는 기존 세계관과 같은 규칙을 따른다.
