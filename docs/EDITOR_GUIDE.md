# 이야기 작업실 사용 안내

공연 화면에서 **세계관과 무대 편집**을 열면 `/lores`의 작업실로 이동합니다. 왼쪽에서 세계관을 고르고, 위쪽 탭에서 편집할 항목을 선택합니다. 카드의 **편집**을 누르면 입력 폼이 열립니다. 변경은 해당 폼의 저장 버튼을 눌렀을 때 적용됩니다.

## 세계관

이름, 배경과 분위기, 규칙, 이야기가 시작되는 씬을 수정합니다. 시작 씬을 바꾸면 초기 동행 인물의 시작 위치도 함께 옮깁니다. 현재 공연의 위치는 바뀌지 않으며 초기화할 때 새 시작 설정을 사용합니다.

**서술 문체 지침**에는 원하는 문장 길이·어휘·리듬·묘사 방식을 자유롭게 적습니다 (최대 4000자). 예를 들어 “담백한 현재형. 행동은 구체적인 동작 위주로 1~2문장만 묘사하고 과한 비유와 감정 해설을 줄인다. 대사는 각 인물의 평소 말투를 살린다.”라고 지정할 수 있습니다. 빈칸으로 저장하면 기본 문체를 사용합니다.

지침은 상세 행동·대사 생성 프롬프트에만 추가합니다. 행동 여부·옷차림 판단과 관계·메모 해석에는 전달하지 않습니다. 캐릭터 성격과 고유 말투, 행동/대사 분리 및 JSON 검증은 유지합니다. 모델에 전달하는 지침이므로 문체 준수 정도는 모델에 따라 달라집니다. 저장하면 진행 중인 미확정 생성은 기존 편집 규칙대로 중단되고, 다음 생성부터 새 지침을 사용합니다. 기존 기록을 다시 쓰지 않으며 세계관별로 저장하고 저장 슬롯·내보내기에도 포함합니다.

## 씬

씬 카드의 **인접 씬 목록**에는 선택된 장소만 태그로 표시합니다. **추가할 인접 씬 검색**에 이름이나 ID를 입력하고 드롭다운 결과를 선택한 뒤 **추가**를 누릅니다. 입력란에서 방향키로 결과를 이동하고 Enter로 선택할 수도 있습니다. 태그의 **×**는 해당 연결을 제거합니다. 추가·제거는 **씬 저장**을 눌렀을 때 적용됩니다. 자기 자신과 이미 추가한 씬은 후보에서 제외하고, 검색 목록은 펼쳤을 때만 화면에 만듭니다.

각 씬의 인접 목록(`exits`)이 연결의 기준이며, 위쪽 **씬 연결 지도**는 저장된 목록을 2차원으로 자동 배치합니다. 연결된 장소를 가까이 두고 노드가 겹치지 않도록 간격을 조정합니다. 저장 데이터에 좌표나 별도 연결을 추가하지 않습니다. **+ / −**로 확대·축소하고 **전체 보기**로 화면에 맞춥니다. 확대한 지도는 스크롤할 수 있습니다. 그래프 배치상의 거리는 실제 이동 거리나 시간을 뜻하지 않습니다.

양쪽 씬이 서로를 목록에 넣으면 ↔, 한쪽만 넣으면 →로 표시합니다. 기존 씬 수정과 새 씬 생성 모두 해당 씬의 목록만 저장하며, 반대쪽 목록은 자동으로 바꾸지 않습니다. 연결되지 않은 장소도 지도에 표시하고 넓은 지도는 스크롤할 수 있습니다.

복도·계단·마당도 **새로운 씬 만들기**에서 일반 장소와 동일하게 만듭니다. 인물·사물 배치와 대화·상호작용이 가능하고, 복도에 들어오고 나가는 사건도 기록됩니다. 예를 들어 `로비 ↔ 복도 ↔ 무대`라면 로비 목록에는 복도, 복도 목록에는 로비·무대, 무대 목록에는 복도를 넣습니다. 플레이어와 LLM 모두 현재 씬의 목록에 등록된 곳으로만 한 구간씩 이동합니다. 거리·이동 시간·통행 조건은 이번 그래프에 추가하지 않았습니다.

씬 카드에서 이름·설명·이곳에서 갈 수 있는 씬을 편집합니다. 이름을 바꿔도 씬의 ID는 유지하므로 배치·현재 위치·기억의 연결은 유지됩니다.

자기 자신이나 없는 씬으로의 연결은 저장할 수 없습니다. 씬 편집은 현재 위치·진행·기억을 유지합니다.

## 캐릭터·사물

캐릭터 카드에서는 **기본 외모**, **옷 취향**, **음식 취향**, **오늘의 옷차림 후보**도 편집합니다. 후보는 이름·차림·착용 맥락을 입력하고 추가·제거할 수 있습니다. 첫 등장과 날짜 변경, 충분한 시간이 지난 뒤 다른 씬에 등장할 때 판단 모델이 후보를 고릅니다. 최소 간격은 **세계관** 탭에서 바꾸며 기본값은 180분입니다. [인상착의 선택과 저장 규칙](CHARACTER_PRESENTATION.md)을 참고하세요.

기존 기본 설정을 카드에서 펼쳐 수정하거나 새로 만듭니다. 캐릭터는 기본 이름, 소개, 성격·말투, 바라는 것과 처음 상태를 편집합니다. 사물은 기본 이름, 소개와 처음 상태를 편집합니다. 캐릭터·사물 필터로 목록을 좁힐 수 있습니다.

소개·성격·목표는 같은 기본 설정을 사용하는 인스턴스들에게 적용됩니다. 배치된 인물의 이름·위치·기억·관계는 별도로 유지합니다. 기본 상태는 새 배치와 초기화에 사용하되, 배치별 시작 상태가 있으면 그 값을 우선합니다. 기존 캐릭터를 사물로 바꾸는 기능은 제공하지 않습니다.

상호작용의 조건·효과와 자동 사건 반응은 카드 안의 **고급 설정**에 있는 JSON 입력을 사용합니다. 일반적인 인물·장소·관계 편집에는 JSON을 입력할 필요가 없습니다.

## 배치·관계

캐릭터 배치의 **겉모습과 옷차림**, **플레이어와의 처음 설정**은 공연 화면의 소개에 표시됩니다. 처음 설정에는 플레이어가 아는 관계만 쓰고 인물의 속마음은 상대별 관계에 적습니다. 현재 옷차림을 수동 수정하면 당장 자동 선택으로 덮어쓰지 않습니다.

카드에서 편집할 시점을 선택합니다.

| 시점 | 저장 결과 |
| --- | --- |
| **지금의 모습** | 현재 이름·위치·동행·상태·관계에 적용. 기억과 관찰 해석 위치는 유지 |
| **이야기 시작 시점** | 초기 배치와 관계에 적용. 현재 진행은 유지하며 초기화할 때 사용 |

동행을 켜면 현재 편집에서는 플레이어가 있는 씬, 시작 시점 편집에서는 시작 씬으로 위치를 맞춥니다. 동행 상태에서는 위치 선택을 잠그고 함께 움직이는 위치를 표시합니다. 새 배치에서는 선택한 기본 설정을 사용해 인스턴스를 만듭니다.

### 상태 항목

상태는 **이름·종류·값**을 한 줄씩 입력합니다. 글자, 숫자, 켜짐/꺼짐(참/거짓), 비어 있음(null)을 지원합니다. 추가·삭제 버튼으로 항목을 조절합니다. 빈 이름, 중복 이름, 숫자가 아닌 숫자 값 등은 거부하며 기존 저장 내용은 유지합니다.

### 상대별 관계

상대를 고르면 신뢰도·호감도·친밀도·존중도·경계도를 슬라이더 또는 숫자로 조절할 수 있습니다. 평가 체크를 끄면 `null`로 저장하고 수치에는 `—`를 표시합니다. 슬라이더 중앙값을 미평가 점수로 저장하지 않습니다. 인식 메모는 일반 문장으로 입력합니다.

각 인물이 상대를 보는 마음은 독립적입니다. 하린→서연의 관계를 고쳐도 서연→하린은 바뀌지 않습니다. 현재 관계를 수정할 때는 기존 사건의 근거와 관찰 해석 위치를 보존하고, 초기 관계의 근거는 빈 목록으로 둡니다. **이 관계 지우기**는 선택한 시점의 해당 상대 관계만 제거합니다. 객체·자기 자신·없는 인물을 대상으로 할 수 없습니다.

## 고급과 저장

왼쪽 **저장한 세계관 가져오기 → 가져오기 방식**에서 **새 세계관으로 추가**와 **현재 세계관 교체**를 고릅니다. 추가는 같은 이름이라도 별도 항목을 만듭니다. 교체는 선택한 세계관의 ID를 유지하면서 설정·현재 진행·저장 슬롯 전체를 파일의 내용으로 바꾸고, 모델 선택은 기본값으로 되돌립니다. 파일에 슬롯이 없으면 기존 슬롯도 모두 지웁니다. 이전 진행·기억·관계를 병합하지 않습니다. 잘못된 파일이나 오래된 화면에서 보낸 요청은 적용하지 않습니다.

**현재 세계관 삭제**를 펼쳐 **이 세계관 삭제**를 누르면 선택한 세계관과 진행 기록·슬롯·생성 작업을 삭제합니다. 다른 세계관은 유지하고, 현재 항목을 지웠으면 남은 세계관을 엽니다. 마지막 항목을 지우면 비어 있는 **새 이야기**를 열어 새 파일을 가져올 수 있게 합니다. 같은 이름을 구별할 수 있도록 목록에는 짧은 식별자도 표시합니다. 교체·삭제 전에 시작한 미확정 생성은 이전 결과를 저장할 수 없습니다.

**고급** 탭에는 세계관 전체 정의의 JSON 편집기를 남겨 두었습니다. 파일 가져오기·내려받기는 왼쪽 목록에서 사용할 수 있습니다. `/lores?tab=world`, `scenes`, `templates`, `instances`, `advanced` 링크로 특정 탭을 직접 열 수도 있습니다.

서버는 저장할 때 전체 참조와 타입, 세계관 리비전을 검증합니다. 유효하지 않은 변경은 적용하지 않습니다. 성공·실패 메시지는 편집 영역 위쪽에 표시합니다. 초기 설정 편집과 현재 배치 편집 모두 저장 시 리비전을 올리므로 진행 중인 미확정 생성은 중단됩니다. 이미 확정된 사건과 슬롯은 유지됩니다.
