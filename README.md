# newera 사용자 가이드

newera는 세계와 등장인물이 시간에 따라 움직이는 성인용 텍스트 게임입니다. 장면을 읽고 추천 행동을 고르거나 원하는 행동을 직접 적을 수 있습니다. 아무 행동 없이 다음 장면으로 넘어가면 세계에서 일어난 일과 인물의 반응을 볼 수 있습니다. 플레이 내용은 로어별로 자동 저장됩니다.

## 설치하고 실행하기

Node.js 24 이상과 OpenAI 호환 API를 제공하는 로컬 모델 서버가 필요합니다. 모델 서버는 구조화된 JSON 출력(`response_format: json_schema`)을 지원해야 합니다. 기본 채팅 주소는 `http://localhost:1234/v1`입니다.

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

`.env`에서 실행 중인 서버 주소와 모델 이름을 확인한 뒤 `http://localhost:5173`을 여세요. 기본 설정은 아래와 같습니다.

| `.env` 항목 | 기본값 | 용도 |
| --- | --- | --- |
| `NEWERA_LLM_BASE_URL` | `http://localhost:1234/v1` | OpenAI 호환 API 주소 |
| `NEWERA_LLM_MODEL` | `gemma4-26b-a4b-qat-uncensored-hauhaucs-balanced-mtp` | 장면·인물 반응·행동 선택지 생성 |
| `NEWERA_EMBEDDING_MODEL` | `text-embedding-qwen3-embedding-0.6b` | 이전 기억 검색 |
| `NEWERA_LLM_TIMEOUT_MS` | `180000` | 모델 응답 대기 시간(밀리초) |
| `NEWERA_DATA_DIR` | 프로젝트의 `data` 폴더 | SQLite 저장 위치 |

채팅 모델이 응답하지 않거나 JSON 형식을 지키지 않으면 해당 턴은 진행되지 않고 오류가 표시됩니다. 임베딩 모델에 연결되지 않아도 장면은 계속 진행할 수 있습니다.

## 처음 플레이하기

1. 처음 실행하면 기본 로어 **망원동의 세 사람**이 열립니다. 다른 완성형 로어를 플레이하려면 [예제 로어 폴더](static/lore-presets)에서 JSON 파일을 고른 뒤, 상단 **로어 관리** → **로어 가져오기 · JSON**에서 **가져오고 열기**를 누르세요.
2. 플레이 화면에서 현재 시간·장소와 첫 장면을 읽으세요. **대상**에서 인물을 고르면 그 인물에게 할 행동이 제안됩니다. **지정 안 함**은 이동, 탐색, 휴식처럼 특정 인물을 대상으로 하지 않는 행동에 어울립니다.
3. 추천 행동을 누르거나 입력창에 행동을 적고 **보내기**를 누르세요. 선택지를 확인하는 것만으로는 턴이 진행되지 않습니다. 상황이 스스로 움직이게 하려면 **아무 행동 없이 다음 장면으로**를 누르세요.
4. 인물이 먼저 제안하면 **수락한다** 또는 **거절한다**로 답할 수 있습니다. 결과는 장면에 이어지고, 아래 **상태와 기억** 및 **행동 기록**에서 변화를 확인할 수 있습니다.

## 진행과 저장

- 플레이 화면 왼쪽의 **로어 목록**에서 다른 로어로 전환합니다. 각 로어의 현재 세션은 따로 자동 저장됩니다.
- **저장 슬롯 1~3**은 현재 로어의 진행을 따로 보관하는 수동 저장입니다. **저장**은 해당 슬롯을 현재 상태로 덮어쓰고, **불러오기**는 슬롯의 시점으로 현재 세션을 되돌립니다.
- **현재 세션 초기화**는 진행된 턴, 사건, 기억과 인물 수치 변화를 로어의 시작 상태로 되돌립니다. 수동 저장 슬롯은 남습니다.
- 현재 세션 상단의 **대화 내보내기 · Markdown**을 누르면 지금까지의 모든 턴을 시간순으로 하나의 `.md` 파일로 다운로드합니다. 행동과 장면, 현재 답변을 기다리는 인물의 제안이 포함됩니다.
- **상태와 기억**은 선택한 인물의 장기 관계, 현재 반응과 구체적인 기억을 보여 줍니다. **행동 기록**에서 최근 8턴의 사건을 확인할 수 있습니다.

## 로어 설정 바꾸기

상단 **로어 관리**(`/lores`)에서 새 로어를 만들거나 JSON 파일을 가져올 수 있습니다. 현재 로어의 제목, 세계관, era 규칙, 묘사 모드와 등장인물 설정도 이 화면에서 편집합니다. 로어 목록의 **내보내기**는 설정뿐 아니라 현재 진행과 저장 슬롯까지 JSON으로 담습니다.

인물의 **초기 era 수치**를 바꾸면 다음에 시작할 새 세션에 적용됩니다. 플레이 중인 세션의 수치는 유지됩니다. 이름, 인물 설정과 행동 선행 조건은 현재 세션에도 반영됩니다. 행동 조건은 인물별로 `행동 · 수치 · 최소값`을 추가하거나 지울 수 있습니다.

수치를 읽을 때는 다음 구분이 유용합니다.

| 항목 | 의미 |
| --- | --- |
| `BASE` | 등장인물의 체력 같은 자원 |
| `TALENT` / `ABL` / `EXP` | 성향 / 능력 / 누적 경험 |
| `RELATION` | 인물이 특정 대상에게 갖는 장기 관계. 플레이 화면은 플레이어를 향한 값을 보여 줍니다. |
| `PALAM` | 지금 장면의 반응. 새 장면이 시작되면 초기화됩니다. |
| `MARK` | 관계나 경험에서 남은 이력과 사용자 정의 태그 |

직접 입력한 행동이 기존 `COMMAND`에 해당하면 인물별 선행 조건을 검사하고, 실제로 일어난 행동에만 수치 변화를 적용합니다. 이동이나 탐색처럼 다른 행동은 사건으로 진행되며 현재는 수치를 임의로 바꾸지 않습니다. 플레이어에게는 체력 수치나 행동 체력 비용이 없습니다.

**세계관·인물 모듈**은 로어 관리 화면에서 JSON 파일을 설치하고 적용합니다. 세계관 모듈은 한 번에 하나, 인물 모듈은 여러 개를 켤 수 있습니다. 모듈을 꺼도 해당 로어에서 진행한 인물의 수치와 기억은 남습니다. 파일 구조는 [모듈 안내](static/modules/README.md)를 참고하세요.

새 완성형 로어를 직접 만들고 싶다면 [로어 JSON 작성 가이드](docs/LORE_JSON_GUIDE.md)를 따르세요. 원본을 가져오기용 JSON으로 만들고 검증하는 명령(`npm run lore:build`, `npm run lore:validate`)과 [로어 제작 스킬](skills/newera-lore-authoring/SKILL.md)도 포함되어 있습니다.
